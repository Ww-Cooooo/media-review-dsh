# Media Review DSH

**Media Review DSH 是基于 [Media Review Skill](https://github.com/Ww-Cooooo/media-review) 改造的 DeepSeek Harness 原生插件。** 如果想在其他 Agent 中使用，可前往[原版 Skill 的 GitHub 仓库](https://github.com/Ww-Cooooo/media-review)下载和安装（Windows，需支持本机文件访问与命令执行）。

Media Review 专门解决用 AI 做视频时改稿反馈麻烦的痛点。AI 生成或剪完视频并送审后，会自动展开审阅侧栏。像用剪映一样拖时间轴、选画面，直接留下修改意见，核心有三大实用功能：

1. **直接框选画面改：** 不满意哪个区域直接在画面上圈出来，对着区域提修改要求，不用费劲描述“画面左上角、人物右侧”这类位置信息。
2. **时间定位灵活选：** 既能选中一整段时间段落批量提问题，也能精准定格到某一个时间点单独调整，整段修改和细节修正都能满足。
3. **字幕点击秒跳转：** 识别视频中的语音台词，或导入已有字幕；点哪句就直接跳到对应的画面，长视频找内容特别快。

这是独立的 Harness 原生插件，包名为 `media-review-dsh`，与原 Media Review Skill 分开安装、保存记录和升级。由社区独立开发维护，非 DeepSeek 官方插件。

依据：实际安装后的审片界面与版本流转检查，详见 [最终验证](FINAL-VERIFICATION.md) 和 [验证记录](VALIDATION.md)。

[侧栏版实拍：打开审片台 → 直接标注 → 拖动调宽](https://github.com/Ww-Cooooo/media-review-dsh/blob/main/SHOWCASE.md)

## 安装与第一次使用

当前提供 **0.1.0-rc.8** 预发布版，适配 **Windows / DeepSeek Harness 0.2.2-rc.1**。作品送审后自动展开右侧审片台；收起后，输入框上方固定保留 **打开审片台**。拖动侧栏左边缘调宽，视频与意见按宽度并排或上下排列，聊天仍可使用。波形保持 92 px，滚轮缩放和直接标注等原有功能保留。

1. 下载 [插件安装包（tgz）](https://github.com/Ww-Cooooo/media-review-dsh/releases/download/v0.1.0-rc.8/media-review-dsh-0.1.0-rc.8.tgz)；[发布页](https://github.com/Ww-Cooooo/media-review-dsh/releases/tag/v0.1.0-rc.8) 同时提供说明与验证资料 ZIP。安装请选择 tgz，不要选 GitHub 自动生成的 Source code 压缩包。
2. 在 Harness 打开 **插件 → 添加插件**，粘贴 tgz 的本机完整路径，点 **安装 → 立即启用**。升级旧版时，先保存、备份记录，再卸载旧包并安装新版；详见 [更新步骤](INSTALL.md#配置和更新)。若宿主提示重启，从 **应用 → 退出** 完整退出后再打开。
3. 将音视频放进 Harness 工作区，选定制作会话。让会话将文件登记送审，审片台会自动展开；收起后点输入框上方的 **打开审片台**。手动开始用 **更多会话视图（…）→ 新建审片**，已有作品用 **审片记录** 查找；空白会话先发送一条消息，再使用顶部菜单。
4. 波形上拖出时间段，或暂停后直接在画面拖框，随后写意见并保存。拖动审片台左边缘可调宽；关闭时暂停播放并保留意见和位置。

通常用 `ffprobe` 识别媒体；缺少工具时，可在新建审片的“媒体工具不可用？”中选择同一份文件，核对内容后人工审片（512 MB 以内）。若本机原 Media Review 校对台已配置工具，插件可复用其工具路径；不需要安装或调用原 Skill。也可以在审片台顶部的 **设置与存储** 中填写 `ffprobe` 的完整路径。在工具状态页点 **检查并补齐缺失项**，会先复用有效工具，只补缺失或失效的工具与模型。全部缺失时约需下载 580 MB；下载后核验校验值并运行中文台词测试。已有配置不会重复安装，媒体不会上传。手动配置见 [工具准备](INSTALL.md#准备媒体识别工具)。

模型沿用你所绑定制作会话的连接与配置，不另设模型登录。普通桌面用户可按上述界面安装。独立测试环境及没有 `dsh` 命令时的步骤见 [安装详情](INSTALL.md)。

## 一轮审片怎样完成

1. 在波形上拖选时间段，松开即可写意见；拖动两端调整范围。暂停后在画面上直接拖框，每个编号框都能写说明，也可以给同一选段继续加框。参考帧自动保存，点中已有意见即可改文字。
2. 点 **发送修改意见**，核对制作会话和允许改动范围。发送内容单独固定保存；之后再改的文字留在草稿中。发送结果不明确时，在本轮详情重试，继续使用原操作编号。
3. 制作会话读取固定意见、确认接手，实际制作新文件并登记为第 2 版。界面显示等待或处理进度；收到消息不等于已经改好。
4. 新版登记后自动展开原意见与修改版；也可点 **打开审片台** 或台内 **查看修改结果**，对照修改前后的作品，选择 **已改好** 或 **还要修改**。缺少对应时间时，先定位并保存位置。**下一条意见**只跳转位置，不代表通过。
5. 全部意见通过后，本次审片显示 **已完成**。仍有问题时，点 **整理修改意见**，核对内容后再发送；已通过的意见不会再次发送。发现新问题可点 **补充新意见**。

依据：rc.6 测试包已在本地桌面跑完两轮真实返修：第一轮三条意见（两项修改、一项保留），只有仍需调整的一条进入第二轮，全部通过后显示完成。模型实际导出了两个新文件，字幕范围、音量和保留片段经独立检查。此后最终包重新安装并复核变更与返回轮次，未再次重跑视频生成。技术测试执行者的确认不代表用户对作品效果的认可，详见 [验证记录](VALIDATION.md)。

## 查找和检查细节

主页面保留当前步骤和主要动作。按钮旁的小提示支持悬停、键盘聚焦与点击固定；也可以打开 **使用帮助**，逐步查看详情。

- 时间轴支持缩放、移动、选段回放、前后上下文和循环；播放中按 I 标起点、按 O 标终点。空格播放／暂停，方向键细移，撤销与重做就在底部。
- **台词**可调用已有的本地 Whisper 工具，也可导入 SRT／VTT。点句子定位，点加号写对应时间段的意见。识别结果需要人工核对。
- **画面索引**按实际视频生成缩略图；意见可搜索，按修改／保留／讨论及类别、进度筛选。作品管理提供搜索、重命名、归档与恢复。
- 底部导出按钮生成离线资料包，包含 HTML 清单、JSON 意见和带编号框的参考画面；不附带原媒体。没有意见时可直接点 **无需修改，结束**。

## 文件、模型与恢复

媒体通过本机已认证通道读取。Web Client 直接分段播放；当前桌面客户端会先将媒体分块写入本机临时磁盘缓存，再播放和跳转，不把整段视频读成内存附件。首次打开会显示“正在准备播放…”。缓存总量最多 2 GiB，离开审片面板时清理，意外退出残留在下次打开时清理；超过此限制的单文件可按 [安装详情](INSTALL.md#独立命令行测试环境) 建立独立 Web Client 并重新登记；工作区、制作会话和审片记录不会自动从桌面迁移。原文件不被改写，新版须是工作区内另一个实际变化的媒体文件。文件被移动或替换时，已有意见会保留，但播放与提交不可用；从 **版本与轮次 → 原文件移动了？重新选择同版** 选回同一内容的新路径，核对通过后继续原任务；不同内容会被拒绝，须作为新版登记。从 **新建审片** 重新登记会创建新的作品记录，不自动迁移旧意见。工作区被删除或重建时的限制见 [恢复说明](INSTALL.md#配置和更新)。

依据：80,306,152 字节视频的实际播放、分段请求、边界拒绝和并发内存检查，见 [验证记录](VALIDATION.md)。

意见、固定轮次、处理记录、参考帧与播放设置保存在插件配置的 `dataDirectory`。默认位置是 Harness 数据根目录下的 `eh3-media-review`：未设置 `DSH_HOME` 时，Windows 对应 `%USERPROFILE%\.dsh\eh3-media-review`。名称中的历史前缀保留用于记录兼容；这里不读写原 Skill 的任务库。实际路径可在 审片台顶部的 **设置与存储** 查看。

备份前先保存意见并确认成功，再在客户端禁用本插件，复制完整数据目录与所引用的媒体文件；随后可重新启用。禁用、卸载不会主动删除这些资料。原 Harness 工作区记录仍在时，重装后沿用相同数据目录即可读取；这份插件备份不能重建已删除的工作区。更换目录前请备份，插件不会自动搬迁历史资料。

未保存输入同时保留浏览器副本与本机恢复副本，仍应点 **保存** 取得正式保存结果。**草稿与恢复** 支持暂放、归档和逐条比较正文、时间及画面框。同一任务只有一个编辑者，其余窗口只读；明确接管后，旧窗口输入保留，过期保存会被拒绝。意外中断的草稿写入会在下次加载时依据恢复记录继续完成。

依据：真实禁用／启用、卸载／重装、冷启动后的意见和框选回读，以及中断恢复测试，见 [验证记录](VALIDATION.md)。

提交时，意见、时间范围、框选参数、媒体路径和参考帧文件名等元数据会交给制作会话，并可能发送至它配置的模型服务；读取轮次还会提供本地意见文件路径。插件不自动把音频、视频或参考帧的二进制内容放进模型请求。制作会话可以按自身工具权限读取文件，读到的内容可能随工具结果发送至模型服务。

取消排队中的本轮只移除对应请求；已经执行时，界面会说明停止操作将中断目标会话当前任务。

本插件负责审片和返修交接，不内置剪辑引擎、语音模型、云端媒体库或自动发布。本机波形使用已有 FFmpeg，语音识别使用已有 Whisper 和模型；缺失时保留手动标注和字幕导入。遇到不支持的编码，可按 [播放兼容处理](INSTALL.md#播放兼容处理) 另存为 MP4（H.264/AAC）后登记。

## 开发与检查

源码构建需要 Node 24.9 以上；桌面安装使用 Harness 自带运行环境。所有依赖按锁文件安装：

```text
npm ci --ignore-scripts
npm run typecheck
npm run build
node scripts/notices.mjs
npm pack --pack-destination dist
```

构建完成后，可按 [开发与测试](DEVELOPMENT.md) 生成合成测试素材并运行测试；完整语音工具检查需要另行指定本机 Whisper 和模型。

Host、React Client 和 Remote 使用同一业务存储；Remote 编解码器由对应版本官方生成器构建。React 复用宿主实例，UI 依赖和字体随包提供。测试资料、模型连接、运行日志、原始媒体及个人 Skill 不进入安装包。

应用代码许可见 [LICENSE](LICENSE)，第三方代码与字体见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。GSAP 与 `@gsap/react` 使用其 Standard No Charge 条款，整个安装包并非全部按 MIT 授权。

## 恢复的操作入口

- 波形上滚轮缩放时间；旁边保留加减、移动、全览和倍数。波形高度不随时间缩放变大。
- 播放器“更多播放操作”：只听声音、声音对照、精细定位、挂起／恢复。
- “台词”：搜索整句、跟随播放、导入字幕；手动滚动后停止跟随。
- “版本与轮次”：添加新版、本版检查、草稿与恢复、资料位置、本机分析、移动文件后重选同版。
- “我的审片”：搜索来源与编号、状态筛选、排序、分页、批量归档和恢复。
- 导出包含 HTML、Markdown、完整 JSON、独立带编号框的 SVG、原参考图与身份／轮次信息。

技术检查的解码、黑场／静音和取帧结果是检查线索；制作会话另行记录实际看过、听过的范围。最终是否改好由人判断。

## 在其他 Agent 中问清需求

如果你也希望在其他 Agent 中把模糊想法或“不满意”说清楚，可以单独安装原版 [Easy Ask AI Skill](https://github.com/Ww-Cooooo/easy-ask-ai)：Prompt Ready 用于开工前梳理需求、准备执行提示词，Get Clear 用于问清已有成果的修改要求，再按确认的范围返修。按目标 Agent 的实际技能机制接入，详见 [安装与接入说明](https://github.com/Ww-Cooooo/easy-ask-ai#安装与开始使用)。

这是独立的需求澄清工具，不是本插件的其他 Agent 版本，也不是安装本插件的前置依赖。
