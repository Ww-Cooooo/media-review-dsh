## Local setup speech and optional tools

`lib/assets/setup-speech.wav` is project-generated Chinese synthetic speech: “这是字幕测试。今天我们一起检查声音和画面。” It contains no user recording. It was generated with Windows SAPI / Microsoft Huihui Desktop; no Microsoft speech engine is redistributed.

Optional runtime tools are downloaded separately, only on the user's preparation action. Their release licenses remain with the downloaded files. Fixed download specifications are in `src/tool-pins.json`: [FFmpeg 9.0.2 Gyan build](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2), [whisper.cpp 1.7.6](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.7.6), and [multilingual Whisper small model](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1). These executables and model weights are not bundled in this tgz.
